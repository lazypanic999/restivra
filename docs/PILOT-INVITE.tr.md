# Pilot katılımcısına gönderilecek mesaj

Selam! Restivra diye açık kaynak bir araç geliştiriyorum. Mevcut PostgreSQL 17
yedeğini bilgisayarında geçici bir veritabanına gerçekten geri yüklüyor, seçtiğin
SQL kontrollerini çalıştırıyor ve sonucu raporluyor. Yedeklerini bana göndermiyorsun.

Kendi bilgisayarında bir haftalık denemeye katılmak ister misin? İlk kurulum için
Windows, PowerShell 7.2+, Git ve Docker Desktop'ın Linux motoru gerekiyor;
bilgisayarına ayrıca Go, Node veya PostgreSQL kurmana gerek yok.

Sabit pilot sürümü ve adımlar:
https://github.com/lazypanic999/restivra/blob/v0.1.0-pilot.3/docs/PILOT-START.tr.md

Önce örnek verilerle başarılı/başarısız iki testi deniyorsun, sonra küçük ve
kullanmaya yetkili olduğun bir PostgreSQL 17 custom yedek ekliyorsun. Takıldığın
adımları ve günlük kullanımda işine yarayıp yaramadığını duymak istiyorum.
Mevcut yedekleme yöntemini koru; gerçek dump, `.env` veya erişim anahtarı paylaşma.
