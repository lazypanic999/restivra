# Restivra mascot expression pack

The [master badger](restivra-badger-mascot-v1.png) is the character reference:
cream face, charcoal-plum fur, notched ear, crimson vest and return-arrow case.
The six poses preserve those identifying features and use transparent PNGs.
They were generated with the built-in Imagegen tool and visually reviewed.
The [prompt set](badger-poses-v1/prompts.json) records the shared reference and
pose instructions; [validation](badger-poses-v1/validation.json) records image
dimensions and transparent-corner checks.
